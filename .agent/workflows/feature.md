# /feature — Capture a Feature Idea

// turbo-all

## Steps

1. **Read** current feature requests: `docs/FEATURE_REQUESTS.md`
2. **Ask the user** these questions (Socratic Gate):
   - What's the problem this solves?
   - Who benefits? (Content creators / nephew / general users)
   - How urgent is it? (Critical / High / Medium / Nice-to-have)
   - Rough size? (Hours / 1-2 days / 3-5 days / 1+ week)
3. **Append** a new entry to `docs/FEATURE_REQUESTS.md` using the template
4. **Ask**: "Should I add this to the PROJECT_BOARD.md backlog now, or keep it as an idea for later?"
   - If yes → Add to backlog in `PROJECT_BOARD.md`
   - If no → Leave status as `💡 Idea`
5. **Do NOT start building.** The feature goes through the normal planning process when ready.
